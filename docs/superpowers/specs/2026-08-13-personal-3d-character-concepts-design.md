# Personal 3D Character Concept Images

## Goal

Create five portrait reference images from `IMG_0490.HEIC` for evaluating a replacement character in the existing 3D résumé. The images should preserve the subject's recognizable identity while translating him into the playful, exaggerated 3D language of the current project character.

## Shared visual system

- Recognizable traits: short black hair, black round-frame glasses, face shape, eyebrows, eyes, nose, mouth, and overall East Asian appearance.
- Character language: oversized head, narrow shoulders, elongated neck, simplified sculpted forms, tactile clay-like skin and hair, and slightly imperfect handmade surfaces.
- Framing: centered front-facing bust, complete head and shoulders visible, square composition, camera near eye level.
- Rendering: polished stylized 3D portrait, soft studio illumination, subtle skin texture, clear facial volumes, and a plain muted sage-green background inspired by the portfolio scene.
- Wardrobe: simple dark charcoal crew-neck T-shirt without graphics, text, or logos.
- Production constraints: one person only; no stickers covering facial landmarks; no watermark; no written text; no cropped hair or ears; no extra limbs or accessories.
- 3D reconstruction suitability: keep the face readable, avoid extreme profile angles and occlusion, and use consistent clean lighting across all five outputs.

## Five concepts

1. **Nervous grin** — widened eyes looking slightly sideways, raised inner eyebrows, tense asymmetric toothy grimace; closest to the existing project's comic anxiety.
2. **Mischievous smirk** — one eyebrow raised, slight head tilt, sideways glance, restrained crooked smile; playful and clever.
3. **Comic surprise** — very wide eyes, lifted eyebrows, small open mouth, head subtly pulled back; energetic without distorting identity beyond recognition.
4. **Confident squint** — narrowed eyes, one mouth corner raised, chin slightly lifted; cool, self-assured, and cheeky.
5. **Innocent deadpan** — rounded attentive eyes, gently puffed cheeks, tiny closed mouth, almost expressionless posture; cute through understatement.

## Identity and consistency checks

Each output must be visibly the same person and use the same hairstyle, glasses, clothing, proportions, materials, background family, camera, and lighting. Only facial expression, eye direction, and a small amount of head attitude should vary. The result is successful when the five images read as a coherent character set but each emotion is identifiable at thumbnail size.

## Deliverables

- Five separate square PNG images saved under `output/character-concepts/`.
- Descriptive filenames numbered `01` through `05`.
- Built-in image generation using the normalized source portrait as the identity reference and the locally captured portfolio character view as the style reference.
